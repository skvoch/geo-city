# КОНТУР — конструктор рельефных карт

Статическое приложение на русском: карта Leaflet, 3D Three.js, загрузка зданий и дорог OpenStreetMap через Overpass и экспорт бинарного STL в миллиметрах. Собственный сервер и ключи не нужны.

## Запуск

```sh
npm ci
npm run dev
```

## GitHub Pages

1. Загрузите содержимое проекта в репозиторий GitHub, ветка `main`.
2. В Settings → Pages → Build and deployment выберите **GitHub Actions**.
3. Включённый workflow проверит геометрию, соберёт приложение и опубликует `dist`.

Относительный base позволяет разместить проект в подпапке репозитория. Для другой ветки измените `.github/workflows/pages.yml`. Для ручного хостинга: `npm run build`, затем опубликуйте содержимое `dist`.

## Работа

Выберите город из встроенного списка, введите координаты либо переместите карту. Нажатие на карту задаёт центр квадратного участка. После изменения центра или площади нажмите «Создать мою модель». Параметры печати обновляют загруженную модель без новых запросов. Точка ставится внутри участка загруженной модели.

Первый экран — поиск адреса. После выбора открывается карта в стиле чертежа, затем анимация сборки и экран модели с параметрами справа. Учебная геометрия больше не показывается. Загруженная модель использует реальные данные OSM. Автоподсказки после паузы 650 мс (от 3 символов), кнопка поиска и Enter используют Photon: города, улицы, дома и места на русском и латинице. Пользователь выбирает результат с полным адресом; карта перемещается к нему, построение модели запускается отдельно. Повторные запросы кэшируются в памяти (до 50), устаревшие запросы отменяются, тайм-аут — 15 секунд. Список быстрых городов и ввод координат работают без геокодера. Для известных опечаток предлагается исправленный запрос, без скрытой подмены. Любой участок России доступен через карту или координаты, при наличии данных и доступа к внешним сервисам.

## Геометрия

- Высоты: `height`, затем `building:levels × 3 м`, затем заданная высота по умолчанию.
- Поддержаны полигоны, мультиполигоны и дворы через osmtogeojson и векторное правило EvenOdd.
- Дороги приподняты; ширина и высота задаются в миллиметрах модели.
- Модель строится экструзией векторных контуров: вертикальные стены, точные диагонали, внутренние дворы. Manifold объединяет основание, здания, дороги, рамку и точку в замкнутый объём без внутренних поверхностей. Расчёт выполняется в Web Worker.
- Растровая сетка не используется. Детализация 32/64/128 сегментов влияет только на дуги дороги и форму точки; прямые контуры зданий сохраняются при любой настройке.
- STL не сохраняет цвета. Сердце в STL — приподнятый рельеф; для цветной печати назначьте смену цвета в слайсере.
- Рельеф земли и крыши плоские. Минимальный печатаемый размер деталей зависит от принтера; проверяйте результат в слайсере.
- Геометрические тесты проверяют замкнутость, направление рёбер, положительный объём и формат STL.

## Внешние сервисы

Источники можно заменить без пересборки в `public/services.json` (или `services.json` опубликованного сайта). Overpass вызывается только по кнопке; при отказе основного источника используется резервный. Карта использует стандартные тайлы OSM, без массовой загрузки и предзагрузки. Атрибуция отображается на странице. В STL есть краткая атрибуция в заголовке; при распространении модели указывайте «© OpenStreetMap contributors, ODbL» со ссылкой https://www.openstreetmap.org/copyright.

Публичные сервисы не гарантируют доступность или полноту данных в конкретном городе России. Для большой аудитории подключите собственные или коммерческие источники. Соблюдайте https://operations.osmfoundation.org/policies/tiles/ . Геокодер Nominatim не используется.

## Проверка в этой среде

Проверены сборка, геометрические тесты, автоподсказки, выбор участка, отмена загрузки и восстановление реальной модели из текущей сессии. Публичные API могут возвращать ошибки или тайм-ауты. Основной источник — российский VK Maps Overpass, резервный — Private.coffee.

Адрес геокодера задаётся полем `geocoder` в `public/services.json`. Photon допускает умеренное использование публичного сервера без ключа; доступность не гарантирована. Для высокой нагрузки подключите собственный экземпляр. Условия: https://github.com/komoot/photon#demo-server. Проверены запросы `Тюмень Щербакова 88` и `Groningen Reitdiephaven`.

## Пошаговый интерфейс

Поиск → карта → сборка → модель. Точку можно поставить кликом по 3D-модели. Отступ от края задаётся в миллиметрах; основание остаётся прежнего размера. Кнопка «Поделиться ссылкой» сохраняет координаты, участок, точку и параметры в URL. По ссылке модель строится заново из актуальных данных OSM — геометрия может измениться, если карта обновится или источник недоступен. Автоподсказки появляются после паузы; запросы координат подтверждаются Enter. Карта окрашена в синий через CSS-фильтр тайлов, атрибуция сохранена. Во время загрузки показываются реальные этапы без вымышленных процентов; запрос можно отменить. Точные контуры вычисляются в фоновом потоке. Настройки печати раскрываются отдельно; точка ставится кликом прямо на 3D-модели. Анимации отключаются при prefers-reduced-motion. На телефоне параметры расположены под моделью.
